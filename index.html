Setup needed

Open config.js and paste your Spotify Client ID.

  1. Go to developer.spotify.com/dashboard → Create app
  2. Add redirect URI: http://127.0.0.1:8888/callback
  3. Enable Web API + Web Playback SDK
  4. Copy the Client ID into config.js, then reload.
